✨ NEW "Top CPU" / "Top Mem" consumer filter
▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
- Off / >=1% / >=5% / >=10% / >=25%, independently adjustable for CPU and
  Mem, combined with the existing name filter -- narrows a busy process
  list down to whatever's actually using resources
- known gap: no per-process disk or network figures are sampled yet, so
  this covers CPU/Mem only for now

✨ IMPROVED Steady-state CPU usage cut from over 30% to roughly 9%
▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
- cmdline, start time, and live status are now fetched on demand for only
  the selected process, instead of for every process on every sample tick
- on macOS specifically, this avoids a gopsutil trap: Status() forks a `ps`
  subprocess per call, so sampling it for the whole process list every
  tick meant hundreds of process forks a second
